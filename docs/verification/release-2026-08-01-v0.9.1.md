## Publisher handoff

```bash
npm run release -- patch --note "Add atomic batch Skill tagging with CLI and Desktop interoperability"
```

The guarded release script checks npm authentication and version availability, reruns all release gates including `npm audit --omit=dev`, asks for the final `publish` confirmation, bumps the package and lockfile to `0.9.1`, writes the versioned CHANGELOG entry, inspects the package, commits, tags, publishes, pushes, and runs the installed-package smoke test.
